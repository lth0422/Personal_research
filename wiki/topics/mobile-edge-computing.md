# Mobile Edge Computing

> IoT 디바이스의 계산 집약적 잡을 엣지 서버로 오프로딩하는 MEC 패러다임

## 개요
MEC(Mobile Edge Computing)는 IoT 기기의 제한된 연산 자원을 보완하기 위해 엣지 서버에 계산을 위임하는 구조이다. 잡 오프로딩 결정, 서버 자원 할당, 무선 통신 품질을 동시에 고려하는 실시간 스케줄링이 핵심 과제이다.
